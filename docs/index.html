AI in Research

How do infrastructures support underrecognised disciplines, entities and non-traditional researchers in an AI-enabled research?

Agentic tools and AI “co-scientists” increasingly decide what researchers find, read and build on. This library collects seven cases, some documented and some constructed, that show what that looks like in practice. It came out of a workshop breakout group (Neil, Brandeis, Malvika and John).

  • Build evaluationsEach case points to something an AI research tool should detect, mark, refuse or surface.
  • Build sensitivityResearchers using AI tools need to see both the pitfalls and the promise in concrete situations.

How to explore. Pick a case below and read it as a story, a scroll-through narrative with charts. From there, switch to the dossier for the full evidence, with Skim, Read and Deep levels and a checklist for appraising the case yourself. Every case uses the same appraisal checklist, so they can be compared.
